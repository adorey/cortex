# 🚀 Cortex v1.2.0 — Share and Enjoy

> *"Share and Enjoy."* — the motto of the Sirius Cybernetics Corporation.
>
> Two of the packs in this release were written for one project and kept in one checkout. A host project overlaid the market roles and the release cards, but their base was never committed, and since the move to the binary `cortex validate` answered `BASE_NOT_FOUND`. The third comes from a contributor: a second voice for the whole team. This minor release shares all three with every project that uses Cortex.

## Highlights

### 🧪 A second theme: `breaking-bad` ([#138](https://github.com/adorey/cortex/pull/138))

*Breaking Bad* and *Better Call Saul* give Cortex its second personality theme, contributed by @sbotte-consoneo. It covers the same nineteen roles as `h2g2`, with a different voice:
- **@Saul** is the Prompt Manager. @Heisenberg leads the backend, @Mike runs the security audits, @Werner designs the architecture, and so on down to @Gretchen, the innovation funding advisor.
- **The six themed workflows** of `h2g2` have their counterparts: a new feature, a performance issue, a security audit, an architecture review, a regulatory deliverable, and support triage (N2 → N3).
- **The tone is "keep it PG"**: the crime is set dressing, and the content is engineering.

To use it for the team, set `theme = "breaking-bad"` in `cortex.toml`, or run `cortex init --theme breaking-bad`. To use it for yourself only, set it in `cortex.local.toml`.

### 📈 Market intelligence ([#150](https://github.com/adorey/cortex/pull/150))

**Two roles**, in `agents/roles/product/`:
- **`market-analyst`.** It names the buyer before the market and the trigger rather than the need, and maps four rings of competition. Adjacency is scored, not argued. Every claim is graded, and what we will not do is stated.
- **`innovation-funding-advisor`.** It runs the eligibility test before any scheme, and reads R&D and innovation in two columns. The rates and windows of a jurisdiction stay in a capability of the project.

**Two workflows**, in `agents/workflows/intelligence/`:
- **`market-study`**, in seven steps: scoping, internal evidence, external mapping, adjacency scoring, fundability, limits, and a decision document;
- **`innovation-funding`**, in six steps: eligibility triage, state of the art, instruments, evidence, technical file, and arbitration.

**One capability, `practices/competitive-intelligence`.** It grades evidence (✅ verified, 📊 measured, 🌐 declarative, 📐 estimated) and sets comparability rules, the order to search sources in, bias control, ethics, and writing rules.

**The casting.** In `h2g2`, Zarniwoop plays the market analyst and Hotblack Desiato the funding advisor. In `breaking-bad`, it is Elliott and Gretchen Schwartz, two of the founders of Gray Matter.

### 🏷️ Release craft ([#161](https://github.com/adorey/cortex/pull/161))

**A new capability category, `release/`**, with four cards:
- **`semver.md`** — Semantic Versioning 2.0.0: what bumps what, breaking changes, pre-releases, and the deprecation flow;
- **`changelog.md`** — Keep a Changelog: the six sections, the `[Unreleased]` buffer, and a changelog compared with release notes;
- **`conventional-commits.md`** — the type that drives the bump, and the PR title that a squash merge keeps;
- **`release-please.md`** — the Release PR pattern: config and manifest, monorepos, and pre-release branches.

`architect`, `lead-backend`, `lead-frontend`, `platform-engineer` and `tech-writer` load them.

**The `engineering/release-automation` workflow** orchestrates them in six steps, from the versioning decision to the first automated release:
1. strategy and ADR;
2. CI wiring;
3. runtime version exposure;
4. a dry run;
5. documentation;
6. a permissions audit.

## Upgrading

1. Install the binary again: the install line installs the latest release.
2. Set `version = "1.2.0"` in `cortex.toml`.
3. Run `cortex sync`.

If your project overlays the market roles, `practices/competitive-intelligence.md` or the `release/` cards, their bases now exist. The `BASE_NOT_FOUND` that `cortex validate` reported for them is gone.

Nothing else changes.

## Notes

- **Each pack was checked against its layer's format**: the character cards against the theme's existing ones, the workflows against `templates/workflow.md.template`, and the capabilities against the structure in their README. Where a pack fell short, it was completed before the merge:
  - every step of the two market workflows now ends with its deliverable;
  - `competitive-intelligence` gains its quick checklist;
  - Zarniwoop and Hotblack Desiato now point to the project context, like every other card.
- **Every role is cast in every theme.** `breaking-bad` and `h2g2` each map all nineteen roles. The two market roles were cast in `breaking-bad` while the three pull requests were brought together.
- **On CI**, `cortex-core (Python 3.9)` stops before running any test: `ubuntu-latest` is now Ubuntu 26.04, which ships no 3.9 ([#177](https://github.com/adorey/cortex/issues/177)). The 3.9 floor is still checked on macOS, with Apple's 3.9.6.
