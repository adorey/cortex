# 🚀 Cortex v0.10.0 — Quite Definitely the Answer

> *"I checked it very thoroughly," said the computer, "and that quite definitely is the answer. I think the problem, to be quite honest with you, is that you've never actually known what the question is."* — Deep Thought, on the Answer to the Ultimate Question.
>
> Until this release, Cortex answered "which files make up this agent?" twice — once in the runtime's Python, once in the validator's Bash — and the two answers had already drifted apart. Now there is one answer, in one package, checked very thoroughly: every output of the old validator frozen and replayed byte for byte, every fix proven by a test that failed first and a mutation that fails it again. And the agent the runtime calls finally knows what the question is about: the project it works on.

## Highlights

### 🧠 `cortex-core` — one implementation of the cascade

New **`core/`** package, imported as `cortex_core` ([ADR-007](../docs/adr/ADR-007-cortex-core.md)): cascade resolution, merge semantics, the capability catalog, prompt assembly and overlay validation, **standard library only**, Python 3.9 or later. The runtime and `bin/validate-overlays.sh` both run it, so they can no longer disagree on what a cascade resolves to. Every function takes a `base_root`, so the base can live outside the project — the ground ADR-008's global installation builds on. Cortex resolves itself as a test: on the one repository guaranteed to exist, each file is read once.

### ⚡ `validate-overlays.sh` — a shim over the core

Same command, same options, same exit codes — about **77× faster** (200 overlays: 5.4 s → 0.07 s). It needs **Python 3.9 or later** on `PATH` — the Python of Apple's Command Line Tools and of RHEL 9 — until ADR-008's native binary; without one it exits `2` and says so. It runs Python **isolated** (`-I`), its version probe included: validating a project whose root or `PYTHONPATH` holds an `fnmatch.py` or a `sitecustomize.py` no longer runs that project's code. It finds the core through a symbolic link or an exported `CDPATH`, ends quietly on a closed pipe, and treats its two roots as arguments, never as options.

### 🔍 The validator sees what the cascade reads

Freezing the Bash validator before porting it surfaced what it had been missing. Each is now deliberate:

- **`MISSING_HEADER`** — a headerless file at the path of a cortex base is an overlay without its header, not a custom addition: the cascade stacks it. A warning, an error under `--strict`. A headerless `characters.md` stays `NON_OVERRIDABLE`; a `README.md` is documentation, never reported.
- **An absent header key** is `MISSING_FIELD` — the script used to stop at once, with exit `1`, no file named.
- **Where the project sits changes nothing.** Paths come from the root being scanned: a project inside a directory named `agents` — on GitHub Actions, a repository named `agents` — no longer fails every overlay, and one inside a directory named `cortex` has its services checked instead of passing over nothing.
- **What sits behind a symbolic link is checked**, as the resolver reads it; a link loop is entered once.
- **What is read is printed as read**: control characters shown escaped, so an overlay can no longer erase a `✗` and print a `✓` in its place. The workspace's section is headed `── Scope: . ──`.

### 👥 The runtime reads the team tier

The runtime now reads ADR-006's team tier, `agents/project-context.md`, before the developer's — and uses it to select capabilities. That has a cost worth knowing: capabilities are selected for every role alike, so on a workspace whose team context names ten technologies, an architect's system prompt went from 10 KB to 92 KB.

### 👁️ The agent sees the project

An agent the runtime calls now sees what the Prompt Manager reads in the editor ([ADR-002 §9](../docs/adr/ADR-002-cortex-runtime.md#9-amendments)): its system prompt closes on `# Project overview`, `# Workspace services` and `# Project context` — the team, developer and service tiers, and one line per service with its `@alias`. Two consequences, stated where they are decided:

- **It costs** 44 to 66 KB of prompt on a real workspace, on every model call of a run. The API backend now marks the system prompt cacheable. Making the view optional is [#89](https://github.com/adorey/cortex/issues/89).
- **It leaves the machine**: the developer's untracked `project-overview.md` and `project-context.md` go to the model provider with every call. The templates now say so at the top.

A run's `service` must name a folder of the workspace — never climbing out of it, never `agents/` — or it is refused, `422`, in the asynchronous mode as in the synchronous one.

### 🛠️ The `claude-cli` backend, past 128 KiB

Linux caps one command-line argument at 128 KiB, and a prompt carrying the project's files goes past it. The backend now hands the CLI its system prompt in a private temporary file — removed whatever fails — and the task on stdin. It needs a `claude` CLI that knows `--append-system-prompt-file` (verified with 2.1.273).

## Upgrading

- **Python 3.9 or later** must be on `PATH` wherever `validate-overlays.sh` runs — CI images included.
- **`--strict` may start failing** on: a headerless file at the path of a base; a service overlay with no category level that declares `Scope: workspace`; an overlay behind a symbolic link that was never checked before. A headerless `characters.md` at the path of a base fails even without `--strict`.
- **Runtime:** install both packages — `pip install -e ../core -e .` from `runtime/`. The system prompt is larger, and carries the project's own files to the model provider. The `claude-cli` backend needs a CLI that knows `--append-system-prompt-file`.
- **`setup.sh`** now names each scaffolded service by its own alias — `core/api` is `@api` — where it used to leave every one as `@my-project`.

## Notes

- **ADR-007 is Implemented.** What changed during its implementation is in its §9 Amendments, phase by phase; the project view, which changes ADR-002's contract, is amended there instead.
- The ADR README now says when an amendment suffices and when a decision needs a new ADR.
- `SECURITY.md` extends instruction injection to the project's own files, which reach the system prompt of an agent that holds tools.
- CI runs the core suite on Python 3.9 and 3.12 and the resolver's tests on macOS with Apple's own Python; the scaffold job now proves the checks run, not just the shim; one pytest session collects both suites.
