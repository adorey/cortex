# 🚀 Cortex v0.5.0 — Publishable

> *"I've calculated all possible security vulnerabilities. We're doomed."* — Marvin, who at least now has a form to report them on.
>
> Cortex has been public since 0.1.0, with three stars and no licence file — which means nobody could legally use it, fork it or contribute to it. This release fixes that, and the rest of what a public repository is expected to carry.

## Highlights

### 📝 A licence, at last

**Apache-2.0** (`LICENSE`, `NOTICE`). Without a licence file, published code is "all rights reserved" by default: every clone and every fork was legally void. Apache-2.0 rather than MIT for its explicit patent grant, which is what corporate legal teams accept most readily — and cortex's natural home is inside a company.

It also matters downstream: a host project under Apache-2.0 mounts cortex as a submodule and links to its ADRs. An unlicensed dependency contaminates the host's own compliance story.

### 📝 Community documentation

- **`SECURITY.md`** — private disclosure through GitHub advisories, honest response times for a single maintainer, and an explicit scope. It names two classes of issue specific to an agent framework: **instruction injection through a layer** (a role, capability or overlay file able to make an agent ignore its guardrails) and **cascade escape** (an overlay reading or writing outside the host project's paths). Both are in scope; jailbreaks of the underlying model are not.
- **`CODE_OF_CONDUCT.md`** — Contributor Covenant 2.1.
