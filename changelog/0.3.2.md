# 🚀 Cortex v0.3.2 — Cortex reads its own instructions now

> *"I seem to be having tremendous fun."* — Marvin, on discovering the repo he's been maintaining never actually told him to be Marvin.
>
> A tooling patch: this repo *is* Cortex, and it already had `project-overview.md`, `project-context.md`, and the h2g2 theme configured at its root — but no bootstrap file told an AI tool to load them. This release closes that gap.

## Highlights

### 🔧 Self-hosted `CLAUDE.md`

Working on the Cortex repo itself with Claude Code fell back to generic-assistant behavior instead of the Prompt Manager protocol (@Oolon, role dispatch, ADR/CONTRIBUTING awareness) already configured for this project. There was no root `CLAUDE.md` to trigger the bootstrap.

- New: `CLAUDE.md` at the repo root — hand-adapted from `templates/bootstrap-instructions.md`, **not** generated by `setup.sh` (that script targets host projects, not cortex's own repo)
- Paths are local (`agents/roles/...`, no `cortex/` prefix) since this repo *is* the base layer — there's no overlay tier above it
- Points structural/contract changes to `CONTRIBUTING.md` and `docs/adr/` instead of `docs/extending-layers.md`, which documents the overlay convention from a *host project's* point of view and doesn't apply reflexively here

## Breaking changes

None. Tooling only — no change to the cascade contract, `setup.sh`, or any shipped role/capability/personality/workflow.
