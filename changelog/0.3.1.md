# 🚀 Cortex v0.3.1 — Docs catch up with the engine

> *"Don't Panic."* — The Hitchhiker's Guide to the Galaxy, in large friendly letters on the cover.
>
> A documentation-only patch: v0.3.0 shipped a whole runtime, but the front-door docs still described a spec-only framework. This release makes them tell the truth.

## Highlights

### 📖 README — now covers both halves of Cortex

The README described only the design-time spec and never mentioned the runtime that landed in v0.3.0. It now presents Cortex as what it actually is:

- **New framing** — the spec (portable Markdown cascade) *and* the runtime (deployable engine), with the ADR-002 firewall stated up front: *the runtime consumes the spec; the spec never depends on the runtime.*
- **New “⚙️ The Runtime” section** — the agnostic API surface, the three model backends (`demo` / `claude-cli` / `anthropic-api`), persistence, the opt-in security perimeter and async execution, each mapped to its ADR and its enabling env var, plus a copy-paste quick start (local and Docker).
- **Fixed “📁 Structure” tree** — adds the `runtime/`, `mcp/`, `deploy/`, and `bin/` directories that were missing, and corrects the stale `docs/` and `changelog/` listings.
- **Rebuilt “📚 Documentation” index** — grouped into *spec*, *runtime*, and *design & contribution*, with links to `runtime/README.md`, `deploy/README.md`, the API reference (`docs/api/`), the Claude CLI setup guide, and the full ADR set (001 → 005).
- **Updated “📋 Changelog” pointer** — was stuck at v0.2.0; now surfaces v0.3.1 / v0.3.0.
- **Philosophy** — adds the runtime principles (the firewall, domain-agnostic `subject`, swappable backends/state/secrets, opt-in hardening) alongside the existing spec principles.

### 📚 Other docs

- [docs/getting-started.md](docs/getting-started.md) — clarifies it covers the design-time spec, with a pointer to the runtime and deployment guides for the engine.
